# 赛博朋克风格桌面UI项目
基于 PyQt5 开发的现代化霓虹风格桌面应用，包含炫酷粒子特效、动态扫描线、霓虹按钮等视觉效果。

## 项目简介
本项目采用模块化架构设计，实现了包含鼠标拖尾粒子、动态扫描线、霓虹按钮、赛博网格背景等多种视觉特效的主界面，整体风格统一、交互流畅。

## 功能特性
- 🌈 统一主题配色系统，一键切换整体风格
- ✨ 鼠标跟随粒子拖尾特效（支持多种形状）
- 🎆 高性能霓虹按钮（跑马灯/冲击波/Q弹动画）
- 📡 侧边动态扫描线动画
- 🧩 赛博朋克网格背景面板
- 📝 独立日志系统 + 日志窗口
- 🖱️ 全局鼠标位置追踪
- 📦 6个功能页面预留位，便于扩展

## 各模块说明
- **theme.py**：存放所有主题颜色，方便集中修改。
- **logger.py**：配置日志系统，提供 QTextEditHandler 供独立日志窗口使用。
- **particles.py**：鼠标拖尾粒子特效，支持多种形状。
- **tracker.py**：全局鼠标位置追踪，驱动粒子移动。
- **button.py**：带跑马灯、冲击波、Q 弹效果的霓虹按钮。
- **scanline.py**：侧边栏扫描线动画。
- **grid_panel.py**：右侧赛博网格背景，内嵌扫描线。
- **pages.py**：六个空白页面，将来填充功能。
- **main_window.py**：主窗口，组装所有组件，处理交互逻辑。
- **main.py**：程序入口，加载配置并启动窗口。
