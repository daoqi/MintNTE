🤖 手动模式使用说明

⚠️ 重要前提

  • 手动操作 必须在钓鱼界面启动，否则无法识别图标。
  • 确认游戏窗口已锁定（窗口检测页显示“已锁定”），且角色处于钓鱼状态（能看到抛竿按钮）。

🔑 如何进入手动操作状态？

  • 在钓鱼界面按 Q 可以打开海上钓客（卖鱼）。
  • 在钓鱼界面按 R 可以打开渔具商店（买鱼饵）。
  • 点击 UI 中的“卖鱼”、“开始购买”按钮，程序会自动帮你按下对应按键并完成后续操作。

🛒 购买鱼饵流程

  1. 确保处于钓鱼界面。
  2. 设置“购买鱼饵次数”（默认 20 次）。
  3. 点击 “开始购买”。
  4. 程序会：按 R 进店 → 选择万能鱼饵 → 拉满 → 购买 → 确认 → 获得 → 退出商店，循环指定次数。
  5. 全部次数完成后，自动按 E 更换鱼饵。
  6. 期间可随时点击 “停止” 终止。

🐟 卖鱼流程

  1. 确保处于钓鱼界面。
  2. 点击 “卖鱼”。
  3. 程序会：按 Q 进入海上钓客 → 依次卖出高性价比鱼和普通鱼 → 一键出售 → 退出。
  4. 期间遇到发臭鱼弹窗会自动按 ESC 关闭。
  5. 最后会自动回到钓鱼界面。

🛑 停止操作

  • 点击 “停止” 按钮会终止正在进行的卖鱼或购买鱼饵线程。
  • 停止后可能需要手动关闭游戏内的弹窗或界面。
