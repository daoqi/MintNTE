🎣 钓鱼卖鱼/购买鱼饵使用说明

一、智能模式

勾选 “智能买卖鱼饵” 后，程序将完全自动管理鱼饵和鱼舱：

  • 鱼饵不足时 → 自动购买鱼饵并继续钓鱼
  • 鱼舱满时 → 自动出售所有鱼获并继续钓鱼
  • 程序会一直运行，直到达到设定的关机时间（小时）

取消勾选后，下方【二】【三】选项生效，你可以手动选择鱼饵不足/鱼舱满时的行为（关机或继续）。

二、鱼饵不足时

仅在取消智能模式时有效：

  • 选择 “关机” → 检测到鱼饵不足后60秒自动关闭电脑
  • 选择 “购买鱼饵继续钓鱼” → 自动购买鱼饵并继续（不推荐，可能导致死循环）

三、鱼舱满仓时

仅在取消智能模式时有效：

  • 选择 “关机” → 检测到鱼舱满后60秒自动关闭电脑
  • 选择 “清空鱼舱继续钓鱼” → 自动售鱼并继续（不推荐，需配合自动买饵）

四、钓鱼模式说明

  • ROI钓鱼：通过颜色识别浮标位置进行跟随，资源占用低
  • A_I钓鱼：使用AI模型识别浮标（需额外模型文件）
  • AI训练中：预留接口，暂不可用

五、手动操作

  • 卖鱼：立即启动一次完整的卖鱼流程（需在钓鱼界面或者卖鱼界面）
  • 购买鱼饵：按设定次数循环购买鱼饵
  • 停止：中止正在执行的手动操作
